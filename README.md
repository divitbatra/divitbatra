## Selected work

### Social Media Moderation Tool

**Flutter / Dart** | Hackathon prototype | [Source](https://github.com/divitbatra/Social-Media-Moderation-Tool)

A Flutter prototype for reviewing social-media comments and surfacing AI moderation categories across Instagram, Reddit, and YouTube. Platform-specific fetch and moderation flows bring asynchronous results into dedicated views. The categories reflect model output, not validated truth detection.

HackED 2024 AltaML Challenge winner.

### Cloud App Development Capstone

**Django / Python** | IBM full-stack coursework | [Source](https://github.com/divitbatra/Cloud-App-Development-Capstone) / [Architecture](https://github.com/divitbatra/Cloud-App-Development-Capstone/blob/master/capstone-project-model.png)

A Django coursework application connecting dealership reviews, relational car models, and cloud-backed data services. Car models live in SQLite, while Cloudant-backed services provide dealership and review data through Cloud Functions. An authenticated review workflow connects these parts in the application.

### Book Reviews Web Application

**Node.js / Express** | IBM coursework | [Source](https://github.com/divitbatra/Book-Reviews-Web-Application)

A coursework API for browsing books and working with reader reviews. Separate routers organize the API; Promise and async flows support book lookups by ISBN, author, and title. User-associated review routes support adding, updating, and deleting reviews, separate from general book browsing. Sample books and users are held in memory.

## Engineering values

I value understandable workflows, visible failure paths, and AI output that people can inspect. I prefer making a system's boundaries clear to hiding uncertainty behind an impressive interface. For automation, I care about knowing what happened, what failed, and what still needs human judgment.

## Current direction

I'm exploring AI-assisted workflows, developer tooling, and reliable automation: ways to reduce repetitive work while keeping the underlying behavior easy to reason about.
